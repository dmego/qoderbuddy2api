# 2api Admin Console 视觉系统与账号详情重构设计

## 目标

解决管理台页面之间字号、字体、控件高度、面板密度不一致，以及账号详情内容数量变化导致布局尺寸和视觉层级不稳定的问题。保留现有业务 API、数据查询、操作确认和敏感信息保护语义，只重构展示层。

## 范围

### 本次包含

- 全站基础视觉变量与控件基线：字体、字号、行高、间距、控件高度、边框和面板层级。
- 页面骨架和数据状态的统一：页面标题、内容区、面板头、加载/空/错误状态。
- `AccessibleDrawer` 的统一居中 Dialog 规范：固定最大宽度和视口高度，内部滚动，不随内容数量改变外层尺寸。
- `AccountDetailPage.vue` 信息架构和布局重构。
- 账号池弹窗调整为摘要级信息，完整详情通过独立详情页查看。
- 前端测试、构建产物和视觉回归所需的稳定 DOM hooks。

### 本次不包含

- 后端 API、数据库、凭据协议、账号操作语义变更。
- 新增业务指标或新的自动化流程。
- 全量重写每一个页面的模板；现有页面通过基础样式和共用组件基线对齐。
- 引入新的字体网络依赖、渐变、玻璃拟态或装饰性动效。

## 设计基线

### 字体与字号

- 正文默认使用现有系统无衬线字体；账号 ID、请求 ID、版本号和数值使用等宽字体。
- 页面标题 22px / 1.3；面板标题 15px / 1.35；正文 14px / 1.5；辅助信息 12px / 1.45；最小可读信息不低于 12px。
- 关键数值 24px；表格和指标行不再使用页面级等宽字体。

### 尺寸与间距

- 间距只使用 8、12、16、24、32px。
- 普通控件高度 36px；紧凑控件 32px；图标按钮点击区域不低于 40px。
- 页面最大内容宽度保持 1480px；页面左右内边距在桌面端 28px、移动端 16px。
- 面板统一 1px 边框、固定内边距 16px，不通过内容数量决定外层最小高度。

### 色彩与动效

- 保留当前暗色画布和琥珀强调色，状态色只使用成功、警告、错误三组语义色。
- 不新增蓝紫渐变、发光背景、玻璃效果或大面积装饰阴影。
- 交互过渡控制在 150ms 左右，并遵守 `prefers-reduced-motion`。

## 账号详情页信息架构

页面固定为以下顺序，数据多少不改变主要区域的网格关系：

1. **标题栏**：账号名称、服务提供方/账号 ID、返回账号池、刷新视图。标题栏保持固定最小高度。
2. **状态摘要**：来源、总体状态、账号启用、最近更新时间四个固定字段；环境变量账号使用单行警示条。
3. **操作栏**：刷新、探测、验证签到、重新授权/提升、删除；危险操作继续使用确认对话框。
4. **用途与路由**：显示名称、启用开关、代理请求和签到开关；保存操作固定在区域底部。
5. **积分与配额**：使用统一指标行；缺少数据时保留固定空状态高度，不渲染伪造的 0。
6. **积分趋势**：图表容器固定高度 280px，ECharts tooltip 显示时间和积分值；无数据时占用相同高度。
7. **凭据元数据、最近请求、签到历史**：三类信息使用相同的列表行组件和状态列，不把可变文本撑大外层布局。

桌面端使用“主列 + 辅列”两列网格，主列最小宽度 0、辅列宽度 320px；窄屏切换为单列但保持上述顺序。文本长时在行内换行，不能改变标题栏、图表和操作区的固定高度。

## 居中 Dialog 规范

- 桌面端宽度 `min(760px, calc(100vw - 32px))`，高度 `min(86vh, 860px)`。
- 移动端宽度 `calc(100vw - 24px)`，高度 `min(88vh, 760px)`。
- 外层遮罩居中布局；内容区 `overflow: auto`；标题栏固定在内容顶部。
- 保留遮罩点击关闭、关闭按钮、Escape、Tab 焦点陷阱和关闭后的焦点恢复。
- 账号池弹窗仅显示来源、身份、总体状态、用途和即时刷新/探测操作；不重复完整详情页的凭据、趋势、请求和签到历史。

## 错误、加载和空状态

- 加载态、空状态、错误态使用统一最小高度和统一字号。
- API 错误在对应面板内显示，提供重试按钮；不以整页布局跳动的方式展示。
- 指标状态为 unknown/stale 时保留状态标签和最后采集时间，不把未知值转换为 0。

## 验收标准

- 所有页面正文、辅助信息、标题和控件字号遵循同一组 CSS 变量。
- 账号详情页在无凭据、无指标、长账号 ID、长错误文本和完整数据五种情况下，标题栏、操作栏和积分趋势区域尺寸稳定。
- 居中弹窗在桌面和移动断点不出现横向滚动；键盘可以完整打开、操作、关闭并恢复焦点。
- 账号池弹窗不再展示与独立详情页重复的大块历史内容。
- 前端 typecheck、lint、Vitest、build 和 `git diff --check` 通过。
